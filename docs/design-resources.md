# Recursos de diseño

Lista de referencias del equipo para el frontend. Las librerías que se usan en el código y cómo se
usan están en `.claude/rules/frontend.md`.

| Uso | Recurso | Nota |
|---|---|---|
| Bloques ya hechos | [21st.dev](https://21st.dev), [shadcndesign.com](https://www.shadcndesign.com/) | Son de React: solo referencia visual de sidebars, paneles y tablas; se reimplementan con shadcn-vue |
| Componentes animados (originales) | [Aceternity UI](https://ui.aceternity.com), [Magic UI](https://magicui.design), [React Bits](https://reactbits.dev), [Motion Primitives](https://motion-primitives.com) | React: referencia visual. Sus ports a Vue son Inspira UI y Vue Bits |
| Inspiración UI | [Refero Styles](https://styles.refero.design), [Mobbin](https://mobbin.com), [Godly](https://godly.website), [minimal.gallery](https://minimal.gallery), [60fps.design](https://60fps.design), [beautifului.dev](https://www.beautifului.dev), [component.gallery](https://component.gallery), [navbar.gallery](https://www.navbar.gallery), [cta.gallery](https://www.cta.gallery) | Buscar dashboards de analítica o inteligencia y paneles laterales de detalle |
| Principios | [Vercel Design Engineering](https://vercel.com/design/engineer) | Checklist de calidad de interacción |
| Assets | [3dicons.co](https://3dicons.co), [backgrounds.supply](https://www.backgrounds.supply) | Solo para landing o hero si sobra tiempo (P2) |
| Mapa de LATAM (P2) | ECharts | Sin librería de mapas aparte |
